# Gaurav Negi — Portfolio

> A dev/QA-themed personal portfolio built around a CI/CD pipeline metaphor — because that's how I actually think about my work: build it, test it, ship it.

🔗 **Live:** [gauravnegi33.github.io/portfolio](https://gauravnegi33.github.io/Personal-Portfolio/)

---

## 🖥️ About

This is my personal portfolio site, designed to look and feel like a developer's terminal and build pipeline rather than a generic template. It showcases my projects, skills, and experience as a B.Tech CSE student currently interning as a Full-Stack & QA Intern and an AI/ML Intern.

## ✨ Features

- **Live terminal intro** — types out a real `whoami` / `cat status.txt` sequence on load
- **CI/CD-themed skills section** — skills grouped into Build → Test → Deploy → Monitor stages, with a "CHALLENGE CLEARED" reveal animation on scroll
- **Project showcase** — repo-card style layout with difficulty tags and live/code links
- **Git-log styled experience timeline** — work history shown as commit entries
- **Custom cursor & kinetic typography** — subtle scroll-linked motion, disabled automatically for users with reduced-motion preferences
- **Fully responsive** — works across desktop, tablet, and mobile
